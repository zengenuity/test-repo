# Contributing

Thank you for your interest in contributing! Here's how you can help.

## Reporting Bugs

- Open a [GitHub issue](../../issues/new) with a clear title and description.
- Include steps to reproduce the bug, expected behavior, and actual behavior.
- Add any relevant logs, screenshots, or environment details.

## Suggesting Features

- Open a [GitHub issue](../../issues/new) and label it as a feature request.
- Describe the problem your feature would solve and how you envision it working.
- Be open to discussion — your idea may evolve through feedback.

## Pull Request Process

1. Fork the repository and create a branch from `master`.
2. Make your changes, keeping commits focused and well-described.
3. Ensure your changes don't break existing functionality.
4. Open a pull request with a clear description of what you changed and why.
5. A maintainer will review your PR and may request changes before merging.

## Code of Conduct

All contributors are expected to be respectful and constructive. Harassment, discrimination, and abusive behavior will not be tolerated. By participating, you agree to uphold a welcoming and inclusive environment for everyone.
